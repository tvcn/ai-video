MiniMax H3: native audio, 9 references, and the 2K cloud line

H3 is the dialogue/product workhorse: native audio, up to 9 images + 3 videos + 3 audio references, 5–15s, 768p local / 2K cloud. It is not a 30s model and not a budget 4K model.

Dialogue recipe

One line per shot, 8–12 Chinese characters or 6–10 English words. Keep the face frontal and unobstructed. Put the audio reference first, then the character image. If lip sync fails, shorten the line before changing the model.

Product recipe

Use 3–5 references: front, side, label close-up. State the label language and ask for no invented text. If the label still garbles, generate a clean plate and add typography in post.

Local vs cloud

Local 768p is for iteration and privacy; 2K cloud is for finals. Local needs 24GB VRAM and 64GB RAM; below that, use cloud. H3 licenses have region and commercial restrictions; check before a client project.

Do not

  • Do not ask H3 for a 30s take.
  • Do not use 9 references as 'more is better'; each must be consistent.
  • Do not master audio in headphones only.

Prerequisites

  • H3 account/API or 24GB local
  • One character reference
  • One line of dialogue
  • Audio check on phone

Steps

  1. Write one line of dialogue.
  2. Prepare 1 character + 1 product ref.
  3. Run 5s 768p.
  4. Check face/lip/audio on phone.
  5. If good, try 2K cloud for the final.
  6. Record cost per usable second.
  7. Write when to use H3 vs Kling.

Copy-ready prompts / settings

H3 dialogue prompt
Character C01, front-facing close-up, says: “You knew it all along, didn't you?”
One sentence, 8–12 Chinese characters / 6–10 English words.
Fixed camera, soft window light from the right, 5 seconds, 9:16.
Realistic, low saturation, no on-screen text, no logo.
Audio: clear, close, no music.

Checks

  • Audio is clear on phone.
  • Lip sync holds for the full line.
  • Face does not drift.
  • Label has no invented text.
  • Cost per usable second is known.
  • License/region checked.

The three-shot test

Generate the same dialogue, action and product shot on every candidate. Record face, hands, physics, text, motion, audio, time and cost. A model that wins the demo but fails your product label is not your model.

Exit rules

  • If a model fails the same shot twice for the same reason, stop.
  • If cost per usable second is above your ceiling, downgrade resolution, not ambition.
  • If the model is discontinued or region-locked, move before you build a series.

Prerequisites

  • Three test shots
  • A budget
  • A machine spec

Steps

  1. Write your three shot types.
  2. Pick two candidates per type.
  3. Run 3 attempts each at 720p.
  4. Score face/hand/text/motion/audio.
  5. Choose primary and backup.
  6. Write one 'never' per type.
  7. Date the matrix.

Checks

  • Each shot type has a primary and a backup.
  • At least one 'never' is written.
  • Cost per usable second is calculated.
  • Discontinued models are excluded.
  • Matrix has a date.

Symptom table: first fix, second fix

Start with the visible symptom. Do not change the model, the prompt and the seed at the same time; then you learn nothing.

SymptomLikely causeFirst fixIf it survives
Extra or fused handsHand action too complexOne hand, one action, hide the otherChange shot size or model
Face driftToo many references / angle changeFront close-up, 2–3 refsLock the character / recast
Flicker or texture boilTemporal model or too much detailShorter clip, simpler backgroundTry another model
Garbled textModel-rendered textRemove text from promptShoot the label / add type
Lip sync offSide face, covered mouth, long lineFront close-up, 5s lineHuman or H3 native audio
Background jumpsCut or camera moveLocked-off, one backgroundSplit into two shots
Audio driftsSeparate audio pipelineGenerate audio with pictureAlign in edit
Too slow / expensiveToo many retries720p, 5s, three takesChange stack

Fix order: symptom → variable → retest

Write the symptom in six words or fewer. Name the one variable you will change. Run three takes with everything else fixed. If all three fail, change the next variable. Do not judge a model on one bad take.

When to stop

Stop when the shot is usable at 50–70%, or when three takes on the same variable fail. ‘Usable’ means the audience will not notice at normal speed. Do not chase a perfect frame that the story does not need.

Prerequisites

  • The original prompt, seed, model and settings.
  • The failed clip, not just a screenshot.
  • A retry cap: three takes per variable.
  • Read /en/lab/ for the first-test log.

Steps

  1. Reproduce the failure at 5s/720p.
  2. Name the symptom in six words.
  3. Change one variable only.
  4. Run three takes and log the result.
  5. If all three fail, change the next variable.
  6. If two variables fail, change the shot or model.

Copy-ready prompts / settings

Fix-test control prompt
Subject: ____ (one character or product).
Shot: locked-off medium close, one action, one background.
Output: 5s, 9:16, 720p; three takes.
Keep constant: seed if supported, light direction, lens, duration.
Change one: hand action / reference count / background / model.
Negative: extra hands, face swap, text, camera shake, background jump.

Checks

  • Symptom is named in six words or fewer.
  • Only one variable changed.
  • Three takes were run before changing the model.
  • The retest is logged with face, hands, text, audio, time, cost.
  • A stop rule was written before retrying.

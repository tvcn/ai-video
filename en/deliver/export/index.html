12 QC checks

  • Correct ratio, no black bars or stretch.
  • Length fits the platform; no trailing black frames.
  • Resolution/frame rate stable.
  • Bitrate high enough; shadows not blocky.
  • Captions accurate, not covering faces or outside safe area.
  • Dialogue clear on phone speakers.
  • Ambience continuous; music does not mask dialogue.
  • Loudness -14 LUFS, true peak -1dB.
  • Character/costume/light direction continuous.
  • No unlicensed music, brand, or likeness.
  • AI generation / avatar disclosure done.
  • File name/version/platform correct.

Naming and delivery pack

project_episode_version_date_platform_ratio.mp4. The pack includes the video, SRT, cover, QC sheet, rights notes and the project file.

Prerequisites

  • Finished edit
  • Jianying/DaVinci/FFmpeg
  • Target platform
  • SRT + cover

Steps

  1. Set 1080×1920 / 30fps.
  2. Export H.264 8–12Mbps.
  3. Check loudness -14 LUFS / TP -1dB.
  4. Export and proof the SRT.
  5. Pick a cover frame with safe area.
  6. Run 12 QC checks.
  7. Rename and archive.
  8. Upload privately and watch on phone.

FFmpeg reference
ffmpeg -i input.mp4 -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -r 30 -c:a aac -b:a 192k -ar 48000 output.mp4
# vertical 1080×1920; loudness needs a separate two-pass loudnorm

Checks

  • Uploads successfully.
  • Dialogue clear on phone.
  • Captions safe.
  • No black bars/jumps.
  • Loudness/bitrate pass.
  • Rights/disclosure/file name complete.

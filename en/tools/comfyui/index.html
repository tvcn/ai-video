ComfyUI for video: install order, first 5s, and when to stop

ComfyUI is a node-based local studio. It is not required to make AI video; it is required when you want repeatability, privacy, or no per-second cost. If you have less than 16GB VRAM, do not start here.

OutputOne local 5s clip + a hardware limit note + a decision: local or cloud.
Time2–4 hours
Cost¥0 + electricity
LevelIntermediate
Not for8GB laptop, no NVIDIA GPU, or a deadline today.

When to stop using local

  • You need 1080p/4K and your card is 16GB.
  • You need a 30s shot: local 5s is the practical unit.
  • You need exact label text: use H3 or post typography.
  • You spend more time fixing nodes than editing.

Stop conditions

If the first 5s clip cannot export, fix the environment before downloading more models. If it exports but looks worse than cloud, keep local for tests and cloud for finals. Do not buy a GPU before you have a finished video.

Prerequisites

  • NVIDIA 16GB+ (24GB comfortable)
  • 32–64GB RAM
  • 100GB free SSD
  • Basic command line comfort

Steps

  1. Check GPU/RAM/SSD.
  2. Install Python/Git.
  3. Clone and create venv.
  4. Install CUDA PyTorch.
  5. Install requirements.
  6. Install Manager.
  7. Download Wan 5B.
  8. Run 480p 5s.
  9. Record time/VRAM.
  10. Decide local vs cloud.

Copy-ready prompts / settings

First local test
A quiet room, wooden table by a window, a cup of hot water, steam rising.
Fixed medium shot, slight handheld.
Soft window light from the right, realistic texture.
5 seconds, 16:9, 24fps.
Negative: no people, no text, no camera roll, no overexposure, no plastic look.

Checks

  • ComfyUI opens without errors.
  • CUDA is available.
  • One 5s clip exports.
  • You know your VRAM/time.
  • You wrote a local/cloud decision.

MiniMax H3: open weights, speed and cost

H3 is one of the few open-weight 15s video models, with native 32kHz stereo and 768p local / 2K hosted. Its license has regional limits; read it before commercial use.

Fit and no-fit / 适用与不适用

  • Teams needing local inference, fine-tuning/LoRA and data staying on-prem.
  • 4–15s projects with native stereo and a budget below closed APIs.
  • Not for: US/EU/UK/South Korea entities, mandatory 4K, zero-ops teams.

Do this / 怎么做

  1. Read the H3 Community License for region and revenue terms.
  2. Run 768p locally, then use H3-Regenerate-2K for hosted 2K.
  3. Deliver 32kHz stereo; test dialogue language first.
  4. Lock references and scoring before fine-tuning; do not use LoRA to hide script issues.
  5. Cost by GPU hours + power + ops, not API list price.

Avoid / 别踩

  • Reading “open” but not the region clause; excluded regions cannot use commercially.
  • Estimating VRAM from a 33B dense model; quantized still needs large or multi-GPU.
  • Treating local 768p as 2K delivery; 2K is a hosted regenerate.

Go deeper / 继续往下

H3's pitch is moving closed-model capability on-prem, but local is not free: 33B dense, video+audio VAEs and long-sequence decode demand VRAM and parallelism. Validate on hosted API before buying GPUs.

Its license is not Apache: regional exclusions, revenue thresholds and attribution affect commercial use. Put license review first; if your team is in an excluded region, switch to Wan 2.2, LTX or a closed API before signing.

Checks / 验收

  • License region, revenue cap and attribution checked.
  • Both local and hosted costs calculated.
  • Dialogue language is in the 11 stable languages.
  • 2K uses Regenerate-2K, not a 768p upscale.

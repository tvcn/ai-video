10-second tool picker: four questions, three cards

Pick the deliverable, then hardware and budget, then priority. The result is not “the best”; it is what to run first, what to keep as backup, and what to avoid under these conditions.

Change one variable at a time. Run 5s, 720p, three takes on the same prompt before 1080p/4K or 30s.

Directions, not a leaderboard. Prices, quotas and access follow the official pages.

Prerequisites

  • Read /en/start/route/, or already have a defined deliverable.
  • Know your GPU / cloud credit / monthly budget; if not, pick the lowest tier.
  • Prepare a log: model, length, resolution, time, cost, failure type.

Steps

  1. Pick one recipe: drama, product or talking head.
  2. Copy its three to eight beats into a shot list without changing durations.
  3. Run the four questions; get main / backup / avoid cards.
  4. Run only the first test: 5s, 720p, three takes.
  5. Log face, hands, text, audio sync, time and cost.
  6. Change one variable per failure; then decide on 1080p.

Copy-ready prompts / settings

Lab control prompt
Subject: ____ (one character / one product).
Action: ____ (one action completed in 5s).
Camera: locked-off medium close; subject fills half the frame.
Light: soft window light from camera right; clean background.
Sound: room tone only; no music.
Output: 5s, 9:16, 720p; three takes on the same prompt.
Negative: face swap, extra hands, garbled text, camera shake, background jump.

Checks

  • Can name the beat count and total duration of each recipe.
  • Knows the timeline is not video playback, and the recipe is not model footage.
  • The tool result has main, backup and avoid, not a leaderboard.
  • First test is fixed at 5s/720p/3 takes; no 4K first.
  • The log includes face, hands, text, audio sync, time and cost.

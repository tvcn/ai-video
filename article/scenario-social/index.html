抖音/Reels/TikTok/Shorts：规格与节奏

四个平台都竖屏，但节奏、字幕安全区、封面和时长不同。15 秒一个钩子，30 秒一个转折，60 秒一个完整故事；不要一版通投。

适用与不适用 / Fit and no-fit

  • 抖音/Reels/TikTok/Shorts 的竖屏内容。
    Vertical content for Douyin/Reels/TikTok/Shorts.
  • 需要 15/30/60 秒多版本、同一素材复用。
    15/30/60s versions from one shoot.
  • 不适用：横屏 YouTube/影院/电视。
    Not for: horizontal YouTube, cinema or TV.

怎么做 / Do this

  1. 先写 3 秒钩子：动作/问题/反差。
    Write a 3s hook: action/question/contrast.
  2. 15 秒只留一个信息；30 秒加转折；60 秒加结果。
    15s one message; 30s a turn; 60s a result.
  3. 主体在上 2/3，字幕留底部 15%。
    Subject in upper 2/3, subtitles in bottom 15%.
  4. 每 2–3 秒一个视觉变化。
    A visual change every 2–3s.
  5. 每个平台单独做封面/标题/首帧。
    Separate cover/title/first frame per platform.

别踩 / Avoid

  • 一版横屏裁四个平台；主体被切。
    One horizontal cropped for four platforms; subject cut.
  • 前 3 秒放 logo；完播率崩。
    Logo in first 3s; completion collapses.
  • 字幕贴底；平台 UI 遮住。
    Subtitles on bottom; platform UI covers.

继续往下 / Go deeper

竖屏的物理限制是“宽不够”。两个人并排、产品横放、横移运镜都会出画。把主体放中间偏上，用前后景和动作制造变化，比硬加运镜有效。

平台差异不在分辨率，而在“观众预期”。抖音前 3 秒要冲突，Reels 要审美/节奏，TikTok 要真实/原生，Shorts 要信息密度。同一条片可以复用素材，但不能复用开头。

验收 / Checks

  • 前 3 秒有钩子，不是 logo/空镜。
    First 3s has a hook, not logo/empty shot.
  • 主体在竖屏上 2/3，字幕在底部安全区。
    Subject upper 2/3; subtitles bottom safe.
  • 15/30/60 各自成立。
    15/30/60 each works.
  • 每个平台封面/标题单独做。
    Cover/title per platform.

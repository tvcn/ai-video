先定交付，再定路线

路线不是“云 vs 本地”的立场题，而是由交付反推：你要交 9:16 的 90 秒短剧，还是 16:9 的 30 秒产品片？要不要对白？要不要 4K？要不要一周做 20 条？这四个答案，比“显卡多少”更能决定工具。

举个最常见的错配：用户只有 8GB 显存，却先装了 ComfyUI，下了 14B 模型，跑了 20 分钟出一条 480p，最后发现剪映里连字幕都没做。正确顺序是先用云工具跑通一条 15 秒，再决定要不要为“批量/私密”买显卡。

你的条件推荐路线第一条作品不要先做
没有独显 / 8GB 显存A 云起步15 秒 3 镜头，即梦/可灵 + 剪映不要装 ComfyUI
16GB 显存B 本地入门 + 云补镜头本地 5 秒 Wan 2.2 5B + 剪映不要先下 14B/LTX 22B
24GB 及以上C 本地进阶 + 云 2K/4K90 秒短剧或 10 秒 4K不要同时装三套前端
只想先验证创意A 云起步3 条同题 5 秒，选 1 条不要买年度订阅
要批量/私密/长期B 或 C 本地固定工作流 + 批量命名不要按秒付费跑草稿

四问诊断：每个答案对应什么

第一问“想做什么”决定任务线；第二问“手里有什么”决定生成端；第三问“能花多少”决定模型档位；第四问“多久要交”决定你是先学 5 秒，还是直接上 90 秒。四问没有标准答案，但必须有一个当下答案。

问题选项会改变什么
1. 想做什么短剧 / 15 秒 / 产品 / 口播 / 品牌 / MV / 教程 / 旅拍决定你走哪条任务线，以及毕业作品
2. 手里有什么无显卡 / 8GB / 16GB / 24GB+ / 已有云额度决定云、本地或混合；决定模型上限
3. 能花多少0–100 / 100–500 / 500–1500 / 1500+决定用免费额度、按秒付费，还是买显卡
4. 多久要交2 小时 / 3 天 / 2 周 / 长期批量决定先做 5 秒样片，还是直接做完整片

云、本地、混合的真实边界

云不是“永远便宜”，本地也不是“零成本”。云的优势是试错快、模型新、不用装环境；本地的优势是批量边际成本低、素材不出门、可以反复跑。混合最常见：本地跑草稿和批量，云端补 2K/4K、长镜头和原生音频。

一个实用判断：如果你一周生成不到 30 条 5 秒素材，云通常更省；如果你每天都要跑几十条，且已有 16GB 以上显卡，本地会开始回本。不要把“电费”忘了，也不要把“你的时间”算成零。

维度云本地混合
上手速度最快，注册即用慢，装环境/下模型先云跑通，再本地
单条边际成本按秒/按条，重复生成也付费电费+时间，跑越多越便宜草稿本地，终版云
分辨率/时长上限看平台，H3 2K、Seedance 30s看显存，H3 本地只 768p各自取长
隐私/素材上传平台，看条款不出本机敏感素材本地
稳定性排队/地区/停服驱动/节点/模型版本准备替代链路

新手最容易做错的四件事

  • 先买显卡再决定做什么：显卡是手段，不是目标。先跑一条 15 秒，确认自己真的会继续做。
  • 把“本地”当成“免费”：16GB 显卡、64GB 内存、SSD、电费、两天安装时间，都是成本。
  • 同时装 ComfyUI、WebUI、Fooocus：三个前端三套模型目录，最后不知道哪个缺节点。
  • 用一条最好看的演示片做决策：至少跑 3 条同题，记录失败类型，才叫测试。

先决条件

  • 一台能上网的电脑；手机也能看，但生成和剪辑建议桌面端。
  • 一个明确的目标片型：短剧、15 秒短视频、产品、口播，或品牌/教程/旅拍。
  • 一个现实的时间盒：2 小时、3 天、2 周。不要写“有空就做”。
  • 一个现金上限：0、100 元、500 元，或“已有 16GB/24GB 显卡”。

操作步骤

  1. 写下第一问答案：你要交的片型、比例、时长、有无对白。写不出来，就先选“15 秒 3 镜头”。
  2. 写下第二问答案：显存、内存、硬盘、系统；不知道就打开任务管理器/系统信息截图。
  3. 写下第三问答案：这个月最多花多少钱；把订阅、按秒、电费分开写。
  4. 写下第四问答案：交付日期；倒推每天能投入几小时。
  5. 按上面的路线表选 A/B/C；不要选“看起来最专业”的那条。
  6. 打开对应任务线总览，记下毕业作品和第一步，不要先下载模型。
  7. 把预算计算器填一遍，确认最坏情况（重试 3 次）还能承受。
  8. 保存路线卡；7 天后再回来看，按实际花费修正，而不是按感觉修正。

验收清单

  • 四个问题都有明确答案，没有“看情况”。
  • 路线卡写了第一条作品、第一个工具、第一笔预算。
  • 知道自己不适合什么：没有 16GB 不推荐本地视频。
  • 知道云的三个风险：排队、地区、停服；知道本地的三个风险：驱动、显存、时间。
  • 预算按“重试 2–3 次”算过，不是按一条成功片算。
  • 路线卡能在 30 秒内讲给朋友听，且他没有听懂就重写。

先分清：视频模型 vs 图像模型

SDXL、SD3.5、FLUX、Seedream、Nano Banana 是图像模型，负责角色卡、关键帧、产品图、风格帧；它们不直接生成视频。视频生成靠 H3、Seedance、Kling、Veo、Runway、LTX、Wan、Hunyuan、Vidu。

“用 SD 做视频”是常见误解：你可以用 SD 做首帧，再让视频模型图生视频；但不要指望 SD 直接出 5 秒。

测试协议：同题 3 条，记录失败类型

每个候选跑同一条 5 秒提示 3 次，记录：脸、手、闪烁、物理、文字、运动六类失败。不要只打分；分数不能解释为什么不能用。

测试要写清：模型/版本、分辨率、时长、参考图、参数、耗时、花费、日期。没有这些，结论三个月后就失效。

先决条件

  • 你的镜头清单/片型。
  • 你的条件：无显卡/16GB/24GB+。
  • 你的交付：720/1080/2K/4K；有无对白。
  • 价格读取日期：2026-11-24。

操作步骤

  1. 写镜头类型和交付规格。
  2. 按“按镜头选”找主选/备选。
  3. 按“按条件选”排除跑不动的。
  4. 按“质量档”排除不能交的。
  5. 每个候选跑同题 3 条，记录六类失败。
  6. 按可用秒成本排序，不按单条最好看排序。
  7. 复核地区/许可/停服状态。
  8. 把结论写进模型卡，标日期。

验收清单

  • 能说出视频模型和图像模型的区别。
  • 选型表有主选/备选/不要，不是“都行”。
  • 价格/分辨率/时长标了日期。
  • 没有“最强/最好”的结论。
  • 每个候选至少 3 条同题测试。
  • 知道 Sora 2 已退场，不作为新项目主线。

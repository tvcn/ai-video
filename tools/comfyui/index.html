安装前检查：三件事

第一，确认显卡型号和显存：任务管理器/GPU-Z 看，不要凭记忆。第二，确认驱动是最新稳定版，不要用 beta。第三，确认 SSD 空间：Wan 2.2 5B + 文本编码器 + VAE + 缓存，至少留 60–100GB。

如果显存 8GB，先接受“480/720p、5 秒、单镜头”；不要一开始就 1080p/14B。

项目最低推荐说明
显存8GB（5B 可卸载）16GB24GB 可跑 14B/H3 768p
内存32GB64GB视频工作流吃内存
SSD100GB200GB+模型/缓存/素材
系统Windows 10/11Windows 11Linux 也可
驱动最新稳定版Studio/Game Ready 稳定不要 beta

Desktop 还是 Portable

ComfyUI Desktop 自带 Python/环境，适合新手；Portable 是压缩包，适合不想装启动器/多版本的人。两者都不要和旧 WebUI 混装。

装完先打开模板库，确认能加载官方 Wan 2.2 工作流；不要先装自定义节点。

版本适合优点注意
Desktop新手/单版本自带环境、更新方便安装包大
Portable进阶/多版本解压即用、可控要自己管 Python/路径
手动 venv开发/自定义最灵活最容易崩

模型目录：放错是“不显示”的第一原因

Wan 2.2 通常需要 diffusion model、text encoder（umt5）、VAE。把文件放到 ComfyUI 的 models/diffusion_models、models/text_encoders、models/vae；LoRA 放 models/loras。不要把所有文件丢在 models/checkpoints。

下载源优先官方/Comfy-Org/HuggingFace/ModelScope；核对文件名、大小、SHA256。不要用来路不明的“整合包”。

文件目录常见错误
Wan 2.2 5B 权重models/diffusion_models放 checkpoints
umt5 文本编码器models/text_encoders缺文件/放错
VAEmodels/vae用错 VAE
LoRA（可选）models/loras触发词没写

第一条 5 秒：固定参数，先不要创作

先用官方模板，不改节点；只改提示词、分辨率、时长、seed。480p、5 秒、单镜头、batch 1。跑通后再 720p，再考虑 10 秒。

如果报错，先看 ComfyUI 控制台最后 20 行；80% 是缺节点/模型路径/显存。不要重装整个环境。

升级路径：5B → 14B → H3/LTX

5B 跑通后，再下 14B（16GB 起，量化更稳）；14B 跑通后再考虑 H3 768p（24GB+64GB 起，权重约 42.5GB）或 LTX 量化。每升一档，先跑同一条提示，记录耗时/显存/质量，不要凭感觉。

先决条件

  • Windows 10/11 或 Linux；NVIDIA 显卡优先，驱动更新。
  • 8GB 显存可跑 Wan 2.2 5B（可卸载），16GB 更稳；内存 32GB 起，64GB 更稳。
  • 至少 100GB 空余 SSD；模型/缓存很大。
  • Chrome/Edge、7-Zip；不要用 IE。

操作步骤

  1. 查显卡/显存/内存/SSD；截图记录。
  2. 更新显卡驱动；装 7-Zip/Chrome。
  3. 装 ComfyUI Desktop 或 Portable；只装一个。
  4. 打开模板库，确认官方 Wan 2.2 工作流能加载。
  5. 装 ComfyUI Manager；先不装其他节点。
  6. 下载 Wan 2.2 5B + umt5 + VAE；核对 SHA256。
  7. 按目录放模型；重启 ComfyUI，刷新节点。
  8. 加载官方模板；480p、5 秒、batch 1。
  9. 写一条简单提示，跑 1 条；记录耗时/显存。
  10. 成功后 720p 再跑 1 条；保存工作流 JSON。
  11. 导出 mp4，剪映拼接/字幕，确认能播。
  12. 把配置/模型/参数写进项目记录。

验收清单

  • 5 秒 ±0.5 秒；能播放；无大面积闪烁。
  • 工作流 JSON 能重新加载并复现。
  • 记录显卡/显存/耗时/模型/参数。
  • 模型目录正确，重启后仍能识别。
  • 没有装无关节点/整合包。
  • 导出 mp4 能在剪映/播放器打开。
